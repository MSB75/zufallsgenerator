ZUFALLSGENERATOR – PWA VERSION 1.5

Inhalt:
- index.html
- manifest.webmanifest
- sw.js
- icons/

Installation / Bereitstellung:
1. Den gesamten Ordner auf einen HTTPS-Webserver hochladen, z. B. GitHub Pages.
2. Die Seite auf dem iPad in Safari öffnen.
3. Teilen > Zum Home-Bildschirm wählen.
4. Danach startet die App im Web-App-Modus und ist nach dem ersten vollständigen Laden offline nutzbar.

Wichtig:
- Service Worker funktionieren nicht zuverlässig beim direkten Öffnen über file://.
- Schülernamen und Verläufe bleiben lokal auf dem jeweiligen Gerät.
- Es werden keine Analyse- oder Trackingdienste verwendet.
