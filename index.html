ⓘ Informationen zur App

🎯 Zweck der App

Die App wählt zufällig Zahlen oder Schülernamen aus und kann aus einer Namensliste zufällige Teams bilden. Große Schaltflächen, klare Bereiche, starke Kontraste und wenige gleichzeitig sichtbare Bedienelemente unterstützen eine möglichst einfache Nutzung.

🔢 Zufallszahlen

Zur Verfügung stehen die Zahlenräume bis 10, 20, 50, 100 und 1000. Zusätzlich können alle Zahlen, nur Zehnerzahlen oder nur Hunderterzahlen gewählt werden. Nicht passende Kombinationen werden automatisch angepasst.

🔁 Wiederholungen

Mit „🔁 Zahlen wiederholen“ dürfen Zahlen erneut erscheinen. Bei „🚫 Keine Wiederholung“ werden gezogene Zahlen ausgeschlossen. Für Namen funktioniert die Einstellung entsprechend. Die jeweilige Auswahl kann jederzeit gelöscht und neu begonnen werden.

👤 Namen zufällig wählen

Im Bereich „Namen & Teams“ werden Schülernamen zeilenweise eingegeben. Die Rakete wählt anschließend einen Namen zufällig aus. Bei ausgeschalteter Wiederholung wird ein bereits gewählter Name erst nach dem Zurücksetzen wieder berücksichtigt.

👥 Teams bilden

Die App mischt alle eingegebenen Namen und bildet daraus 2er-, 3er-, 4er- oder 5er-Teams. Geht die Anzahl nicht genau auf, werden die übrigen Personen möglichst gleichmäßig auf die vorhandenen Teams verteilt. Dadurch entsteht nach Möglichkeit kein einzelnes Restmitglied.

💾 Lokale Speicherung

Die eingegebene Namensliste wird ausschließlich im lokalen Speicher des Geräts gesichert, damit sie beim nächsten Start wieder verfügbar ist. Namen werden nicht an einen Server oder an externe Dienste übertragen. Mit dem Leeren des Eingabefelds werden die lokal gespeicherten Namen entfernt.

🚀 Start und Anzeige

Die Rakete startet die Auswahl. Das Ergebnis erscheint groß in der Mitte. Bereits gezogene Zahlen beziehungsweise Namen werden nur innerhalb der aktuellen Runde berücksichtigt.

🔈 Ergebnis vorlesen

Gezogene Zahlen, ausgewählte Namen und fertig gebildete Teams können über den Button „Vorlesen“ laut ausgegeben werden. Bei Zahlen wird ausschließlich die Zahl gesprochen, bei Namen ausschließlich der Name. Teams werden als „Team 1: …“ vorgelesen. Dafür verwendet die App die auf dem iPad vorhandene deutsche Systemstimme. Die Sprachausgabe erfolgt direkt auf dem Gerät; es werden keine Texte an einen externen Sprachdienst übertragen.

🔊 Ton und Bewegung

Der dezente Ergebniston kann oben rechts ein- oder ausgeschaltet werden. Die Glücksrad-Animation lässt sich im Zahlenbereich deaktivieren und gilt zugleich für die Namensauswahl. Die Systemeinstellung „Bewegung reduzieren“ wird berücksichtigt.

📱 Installation auf dem iPad

Die App in Safari öffnen, auf das Teilen-Symbol tippen und „Zum Home-Bildschirm“ wählen. Danach erscheint das Appsymbol auf dem iPad und die Anwendung startet im eigenständigen Webapp-Fenster.

📴 Offline-Nutzung

Nach dem ersten vollständigen Laden speichert ein Service Worker die benötigten Dateien auf dem Gerät. Anschließend kann die installierte App ohne Internetverbindung genutzt werden. Für die erste Einrichtung ist eine HTTPS-Verbindung erforderlich.

☁️ Hosting und Server

Wird die App über einen Webserver bereitgestellt, kann dieser beim ersten Abruf technisch notwendige Protokolldaten wie IP-Adresse, Zeitstempel und Browsertyp verarbeiten. Die App selbst enthält keine Analyse-, Werbe- oder Trackingdienste.

🐙 Bereitstellung über GitHub

Diese Web-App kann über GitHub Pages bereitgestellt werden. Beim ersten Aufruf können durch GitHub technisch notwendige Server-Protokolle verarbeitet werden, zum Beispiel IP-Adresse, Zeitpunkt des Abrufs und Browsertyp. Diese Daten werden von GitHub verwaltet und sind für den Betreiber dieser App nicht unmittelbar einsehbar. Nach der erfolgreichen Offline-Speicherung kann die installierte App ohne weitere Serververbindung verwendet werden.
